# Project Instructions

- Please add each new prompt into `prompts.md`.
- Please use i18n always with 2 languages: Russian and English.
- Please always create a plan and test plan for new features in `docs/plans`.
- Please always create unit tests.
- After completion of a feature with a test plan, please create a separate pass where you analyze the tests, quality, readability, and reliability of the code and the tests, and write this analysis as the last part of the plan.
- Please duplicate all documentation in English and Russian in separate doc files and keep them in sync. For `README.md` files, keep 2 separate sections instead of duplicating the file.
- Please prioritize official iiko API documentation at `api-ru.iiko.services` over third-party or generated client libraries when there is any mismatch or uncertainty.
